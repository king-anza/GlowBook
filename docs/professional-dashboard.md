# Professional dashboard

The Studio entry point opens a data-backed daily dashboard. It summarises approval and setup progress, today's non-cancelled bookings in the studio's South African time zone, pending booking requests, active staff coverage, published Glow Spaces and pending space applications.

The dashboard never invents activity. Empty states explain the next useful action, while links lead directly to setup, bookings, availability, services and Glow Spaces management.

The shared Studio navigation groups overview, appointment and business tools. On wide screens it is a persistent sidebar; on smaller screens it becomes an explicitly toggled menu with the same destinations and current-page state.
