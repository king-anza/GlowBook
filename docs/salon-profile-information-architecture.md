# Salon profile information architecture

Public salon profiles now provide a scannable path from trust and visual work to booking:

1. Hero image/gallery, approval or demo state, location and rating summary.
2. Jump links to services, professionals, reviews and visit information.
3. Services with professional, duration, price and direct availability actions.
4. Active staff biographies supplied by the business.
5. Customer reviews with existing pagination and retry behaviour.
6. Consolidated opening hours derived from accepting staff availability.
7. Cancellation policy, full address, optional public contact details and a safe external directions link.
8. Amenities with an explicit not-provided state until the data model supports owner-managed facilities.

The sticky booking action uses the first active offering and remains above the mobile bottom navigation and device safe area. Server-side authorization and live availability remain authoritative.
