# Role-choice registration

Registration starts with an explicit account choice:

- **Customer** is selected by default and explains discovery, booking and review tools.
- **Beauty professional** explains studio setup, services, availability and Glow Spaces tools.

The options form an accessible radio group with visible selected and focus states. The submit action repeats the selected role, and automated browser coverage confirms that professional registration uses the dedicated professional endpoint. Both roles can still book customer appointments; professional capabilities remain protected by server-side authorization.
